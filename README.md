# York Google Maps Audit Web App

A clean GitHub Pages web app for reviewing York city-centre and Shambles businesses before pitching a Google Maps Upgrade Pack.

## Features

- Polished visual lead board
- York-style map graphic header
- Search, category filter and priority filter
- Business audit popups
- Google Maps and route buttons
- Local notes saved in your browser
- Export notes as CSV
- Mobile-friendly layout

## How to publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings**.
3. Click **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/root`.
6. Click **Save**.
7. Wait for the live website link.

## Important image note

Do not copy Google Maps photos into this site. Use your own photos, or photos the business gives permission to use.

## Edit the businesses

Open `businesses.js` and add, remove, or change the local businesses.
